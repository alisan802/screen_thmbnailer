# 動画サムネイル生成ソフトウェア 要件定義書

## 1. 文書情報

- 作成日: 2026-09-21
- 対象プラットフォーム: Windows / Linux
- 想定する開発言語: Rust
- 動画処理の前提: FFmpeg 系ライブラリまたは FFmpeg の機能を利用する

本書は、動画から複数の静止画を抽出し、それらを並べたサムネイル画像（コンタクトシート）を生成するデスクトップソフトウェアの機能要件を定義する。ライブラリ構成、内部アーキテクチャ、データ構造などの詳細な実装方法は対象外とする。

## 2. 背景と目的

動画ファイルの内容を再生せずに概観できる画像を、簡単かつまとめて生成できることを目的とする。

主な利用目的は次のとおりとする。

- 動画の内容確認用サムネイルを作る
- 動画の整理・管理に使うコンタクトシートを作る
- 用途に応じて画像の枚数や配置、表示情報を変更する

## 3. 想定利用者

- 手元の動画を整理したい個人ユーザー
- 動画ごとの内容を短時間で確認したいユーザー
- 動画素材を管理するクリエイターや管理担当者
- WindowsとLinuxの両方で同じ操作感を必要とするユーザー

専門的な動画編集知識がなくても利用できることを前提とする。

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| サムネイル | 動画から抽出した1枚の静止画 |
| コンタクトシート | 複数のサムネイルを格子状に並べ、1枚にまとめた画像 |
| 入力動画 | サムネイル生成の対象となる動画ファイル |
| プリセット | 出力枚数やレイアウトなどの設定をまとめて保存したもの |

## 5. 対象範囲

### 5.1 初期リリース（MVP）

初期リリースでは、次の範囲を対象とする。

- デスクトップGUIによる操作
- 1件の動画ファイルの読み込み
- 動画情報の表示
- 動画全体からのサムネイル抽出
- コンタクトシートの生成
- 個別サムネイル画像の出力
- 基本的なレイアウトと画像品質の設定
- 進捗、完了結果、エラーの表示
- WindowsおよびLinuxでの動作

### 5.2 初期リリースの対象外

- 動画の編集、変換、結合、音声抽出
- 動画プレイヤーとしての再生機能
- クラウドストレージへの直接保存
- サーバーでの分散処理
- モバイルOS対応
- AIによる重要シーンの自動選択
- 複数動画の一括処理
- フォルダーの監視および自動処理
- スケジュール実行
- コマンドライン専用操作

これらの項目は本書で定義する開発対象に含めない。

## 6. 基本的な利用の流れ

1. ユーザーが動画ファイルを1件選択する。
2. ソフトウェアが対象動画を読み込み、動画情報を表示する。
3. ユーザーが抽出方法、枚数、レイアウト、出力先などを設定する。
4. ユーザーが生成処理を開始する。
5. ソフトウェアが動画からサムネイルを抽出し、指定された画像を生成する。
6. ソフトウェアが処理結果を表示し、ユーザーが出力画像を確認する。

## 7. 機能要件

優先度は次の区分で表す。

- 必須: 初期リリースに必要
- 推奨: 初期リリースでの搭載を目指す
- 将来: 初期リリース後の拡張候補

### 7.1 入力動画の選択と管理

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-INPUT-01 | 必須 | ユーザーはファイル選択画面から動画を1件選択できること。 |
| FR-INPUT-02 | 推奨 | 動画ファイルを画面へドラッグ＆ドロップして選択できること。 |
| FR-INPUT-03 | 必須 | 選択した動画を画面上で確認できること。 |
| FR-INPUT-04 | 必須 | ユーザーは選択中の動画を解除、または別の動画に変更できること。元の動画ファイルは削除しないこと。 |

### 7.2 動画情報の取得と表示

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-INFO-01 | 必須 | ファイル名、動画の長さ、映像サイズを表示できること。 |
| FR-INFO-02 | 推奨 | ファイル容量、フレームレート、映像・音声形式などの追加情報を表示できること。 |
| FR-INFO-03 | 必須 | 読み込めないファイルや動画として認識できないファイルを明示できること。 |
| FR-INFO-04 | 必須 | 日本語を含むUnicodeのファイル名およびパスを扱えること。 |

### 7.3 サムネイルの抽出

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-CAPTURE-01 | 必須 | 動画全体に偏りが少なくなるよう、指定枚数のサムネイルを抽出できること。 |
| FR-CAPTURE-02 | 必須 | ユーザーは抽出するサムネイルの枚数を指定できること。 |
| FR-CAPTURE-03 | 推奨 | ユーザーは一定時間間隔でサムネイルを抽出する方式を選択できること。 |
| FR-CAPTURE-04 | 推奨 | ユーザーは抽出対象から動画の先頭部分と末尾部分を除外できること。 |
| FR-CAPTURE-05 | 必須 | 抽出した各サムネイルに再生位置のタイムスタンプを表示するか選択できること。 |
| FR-CAPTURE-06 | 必須 | 横長、縦長、回転情報を持つ動画を適切な向きと縦横比で出力できること。 |
| FR-CAPTURE-07 | 必須 | 同じフレームが複数回選ばれるなど、意図した枚数を適切に抽出できない場合は、その結果または警告を表示すること。 |

### 7.4 コンタクトシートの生成

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-SHEET-01 | 必須 | 抽出した複数のサムネイルを1枚のコンタクトシートとして出力できること。 |
| FR-SHEET-02 | 必須 | ユーザーは列数を指定でき、行数はサムネイル枚数に応じて決定されること。 |
| FR-SHEET-03 | 必須 | ユーザーはサムネイルの大きさまたは出力画像の幅を設定できること。 |
| FR-SHEET-04 | 必須 | サムネイル同士の余白、外側の余白、背景色を設定できること。 |
| FR-SHEET-05 | 推奨 | サムネイルに枠線を付け、色と太さを設定できること。 |
| FR-SHEET-06 | 必須 | ヘッダーにファイル名、動画の長さ、映像サイズなどの情報を表示するか選択できること。 |
| FR-SHEET-07 | 推奨 | ヘッダーに任意のタイトルまたはコメントを表示できること。 |
| FR-SHEET-08 | 推奨 | フォント、文字サイズ、文字色を設定できること。 |
| FR-SHEET-09 | 推奨 | 現在の設定による出力イメージを、処理開始前にプレビューできること。 |

### 7.5 個別画像の出力

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-IMAGE-01 | 必須 | コンタクトシートとは別に、抽出したサムネイルを個別の画像として出力するか選択できること。 |
| FR-IMAGE-02 | 必須 | JPEGおよびPNG形式で画像を出力できること。 |
| FR-IMAGE-03 | 必須 | JPEG選択時は画質を設定できること。 |
| FR-IMAGE-04 | 必須 | 出力ファイル名が重複する場合に、上書き、スキップ、または別名保存のいずれかを選択できること。 |

### 7.6 出力先とファイル名

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-OUTPUT-01 | 必須 | 入力動画と同じフォルダー、またはユーザーが指定したフォルダーへ出力できること。 |
| FR-OUTPUT-02 | 必須 | 出力ファイル名に元動画のファイル名を利用できること。 |
| FR-OUTPUT-03 | 推奨 | 出力ファイル名へ任意の接頭辞または接尾辞を追加できること。 |
| FR-OUTPUT-04 | 必須 | 出力先を処理開始前に確認できること。 |

### 7.7 処理の実行と制御

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-PROCESS-01 | 必須 | 選択中の動画に対して生成処理を開始できること。 |
| FR-PROCESS-02 | 必須 | 処理中、進捗と現在の処理内容を表示できること。 |
| FR-PROCESS-03 | 必須 | ユーザーは処理をキャンセルできること。 |

### 7.8 設定の管理

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-SETTING-01 | 必須 | 最後に使用した主要な設定を次回起動時に復元できること。 |
| FR-SETTING-02 | 推奨 | ユーザーは設定一式を名前付きプリセットとして保存、読込、削除できること。 |
| FR-SETTING-03 | 必須 | 設定を初期値へ戻せること。 |
| FR-SETTING-04 | 推奨 | 設定をファイルとしてエクスポートおよびインポートできること。 |

### 7.9 結果とエラーの通知

| ID | 優先度 | 要件 |
| --- | --- | --- |
| FR-RESULT-01 | 必須 | 処理の完了または失敗を表示できること。 |
| FR-RESULT-02 | 必須 | 処理に失敗した場合、その理由をユーザーが確認できること。 |
| FR-RESULT-03 | 必須 | 出力先フォルダーを画面から開けること。 |
| FR-RESULT-04 | 推奨 | 処理結果をログファイルとして保存できること。 |
| FR-RESULT-05 | 必須 | エラー表示は、元の動画に変更や削除が行われていないことをユーザーが判断できる内容とすること。 |

## 8. 非機能要件

本節では実装方法ではなく、製品として満たすべき品質を定める。

### 8.1 対応環境

- NF-PLATFORM-01: Windows 10およびWindows 11の64ビット環境を対象とする。
- NF-PLATFORM-02: 主要な64ビットLinuxデスクトップ環境を対象とする。正式な対象ディストリビューションはリリース計画時に定める。
- NF-PLATFORM-03: Windows版とLinux版で、主要機能と設定項目を原則として共通にする。

### 8.2 対応動画

- NF-MEDIA-01: FFmpegが一般的に扱える主要な動画コンテナと映像形式を対象とする。
- NF-MEDIA-02: 具体的な対応形式は、配布時に利用者向け文書へ記載する。
- NF-MEDIA-03: 対応外または破損した動画を入力しても、アプリケーション全体が異常終了しないこと。

### 8.3 操作性

- NF-USABILITY-01: 初回利用者が「動画を選択し、生成を開始し、結果を確認する」までを画面上の案内だけで行えること。
- NF-USABILITY-02: 既存ファイルの上書きが発生しうる操作では、対象と結果を事前に確認できること。
- NF-USABILITY-03: 長時間処理中も、アプリケーションが操作不能に見えないこと。

### 8.4 安全性と信頼性

- NF-SAFETY-01: 入力動画を変更、移動、削除しないこと。
- NF-SAFETY-02: キャンセルまたはエラー発生時に、不完全な出力を正常な完成ファイルとして扱わないこと。
- NF-SAFETY-03: 動画の処理失敗が、保存済み設定を破損させないこと。

### 8.5 性能

- NF-PERFORMANCE-01: 動画処理中も進捗表示とキャンセル操作に応答できること。
- NF-PERFORMANCE-02: 利用可能なCPUやメモリを過度に占有しないための処理量調整を検討できること。

### 8.6 配布と保守

- NF-DISTRIBUTION-01: WindowsおよびLinuxの各対象環境へ導入できる配布物を提供すること。
- NF-DISTRIBUTION-02: 動画処理に必要な外部コンポーネントの有無と導入方法を、利用者へ明示すること。
- NF-DISTRIBUTION-03: 本ソフトウェアと同梱する外部コンポーネントについて、ライセンス表示と配布条件を満たすこと。

## 9. 画面構成の概念

詳細な画面設計は別途行うが、最低限、次の操作領域を持つものとする。

- 入力動画の選択と情報表示
- 抽出条件の設定
- レイアウトと出力形式の設定
- 出力先の設定
- 生成開始、キャンセル操作
- 処理進捗の表示
- 完了結果とエラー詳細の表示

設定項目が多くなる場合は、基本設定と詳細設定を分け、初回利用者が主要操作を見つけやすくする。

## 10. 初期リリースの受け入れ条件

初期リリースは、少なくとも次の条件を満たした時点で利用可能と判断する。

1. WindowsとLinuxの両方でアプリケーションを起動できる。
2. 一般的な動画ファイルを1件選択し、指定枚数のサムネイルからコンタクトシートを生成できる。
3. JPEGまたはPNGで、ユーザーが指定した出力先へ保存できる。
4. 列数、画像サイズ、余白、背景色、タイムスタンプおよびヘッダー表示を変更できる。
5. 日本語を含むファイル名とパスを扱える。
6. 読み込めない動画について、処理できないことと理由を確認できる。
7. 処理中に進捗を確認し、必要に応じてキャンセルできる。
8. 入力動画が変更または削除されない。
