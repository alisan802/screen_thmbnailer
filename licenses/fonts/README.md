# Embedded font licenses

`eframe`の`default_fonts`機能により、次のフォントが実行ファイルへ埋め込まれます。各通知は`epaint_default_fonts 0.33.3`に同梱された原文です。

| Font | License notice |
| --- | --- |
| Hack Regular | `Hack-Regular.txt`（MITおよびBitstream Vera License） |
| Noto Emoji Regular | `OFL-1.1.txt` |
| Ubuntu Light | `Ubuntu-Font-License-1.0.txt` |
| Emoji Icon Font | `emoji-icon-font-MIT.txt` |
